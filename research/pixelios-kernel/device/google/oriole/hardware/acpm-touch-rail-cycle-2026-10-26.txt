Observed: LDO25M (0x5C) then LDO26M (0x5D) accepted the bit-7 enable
request, each returned the expected enabled value. LDO26M then LDO25M
accepted restoration, each returned its original disabled value. All
request return codes were zero. "published00000002" means the ACPM IPC
doorbell was rung, as defined in shim/acpm.h; it is not a request count.
The host capture script initially rejected this successful log because its
new parser incorrectly expected published00000001; the parser was corrected
and the complete captured log then passed. This test did not read the FTM5
chip ID, produce touch events, or establish an iOS touch path.
